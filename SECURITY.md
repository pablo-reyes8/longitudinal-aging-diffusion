# Security and privacy policy

Please do not open a public issue containing credentials, private face images,
dataset paths, signed model URLs, or other sensitive information. Report a
vulnerability privately to the repository maintainer and include a minimal
reproduction that does not contain personal data.

Supported development currently tracks the latest commit on the default branch.
There are no separately maintained release branches yet.

Before sharing logs, remove Hugging Face tokens, local paths, identity labels,
image metadata, and checkpoint contents. Treat face embeddings and trained
checkpoints as sensitive artifacts even when the original images are absent.
